🎯 QUÉ CREA ESTE PROYECTO
═════════════════════════════════════════════════════════════════════════════

INFRAESTRUCTURA DE RED
  • 1 VPC con CIDR 10.0.0.0/16
  • 4 Subnets (2 públicas, 2 privadas) en diferentes Availability Zones
  • 1 Internet Gateway (acceso desde internet)
  • 1 NAT Gateway (salida de instancias privadas)
  • 2 Tablas de rutas (pública y privada)

GRUPOS DE SEGURIDAD
  • Public-Web-SG: Permite SSH(22), HTTP(80), HTTPS(443) desde internet
  • Private-App-SG: Permite puerto 8080 solo desde Web Servers
  • Private-DB-SG: Permite MySQL(3306) y PostgreSQL(5432) solo desde Web Servers

INSTANCIAS EC2
  • Web-Server-1 (Pública, t2.micro) - Apache + HTML
  • Web-Server-2 (Pública, t2.micro) - Apache + HTML
  • App-Server-1 (Privada, t2.micro) - Servidor Python en puerto 8080
  • App-Server-2 (Privada, t2.micro) - Servidor Python en puerto 8080
  • DB-Server-1 (Privada, t2.micro) - MariaDB + Base de datos

🚀 CÓMO EMPEZAR (3 PASOS)
═════════════════════════════════════════════════════════════════════════════

PASO 1: Inicializar Terraform
  $ cd /home/claude
  $ terraform init

PASO 2: Revisar lo que se va a crear
  $ terraform plan

PASO 3: Aplicar la configuración
  $ terraform apply
  > Escribe "yes" cuando se pida confirmación

LISTO! En 5-10 minutos tendrás la infraestructura creada.

📋 DESPUÉS DE CREAR (Comandos Útiles)
═════════════════════════════════════════════════════════════════════════════

Ver todas las IPs y recursos creados:
  $ terraform output

Ver solo la IP pública del web server:
  $ terraform output web_server_1_public_ip

Ver todos los recursos en el estado:
  $ terraform state list

Ver detalles de un recurso específico:
  $ terraform state show aws_instance.web_server_1

═════════════════════════════════════════════════════════════════════════════

🧪 PROBAR LA INFRAESTRUCTURA
═════════════════════════════════════════════════════════════════════════════

1. ACCEDER AL WEB SERVER:
   $ curl http://<web-server-public-ip>

2. HACER SSH A WEB SERVER:
   $ ssh -i <clave.pem> ec2-user@<web-server-public-ip>

3. DESDE WEB SERVER, CONECTAR A APP SERVER:
   $ curl http://10.0.10.x:8080

4. DESDE WEB SERVER, CONECTAR A BASE DE DATOS:
   $ mysql -h 10.0.10.x -u appuser -p

Para más detalles, ver TESTING.md
